# design-sync — заметки по репозиторию

## Особенности этого репозитория

- **Это приложение, а не библиотека компонентов.** В `package.json` нет `main`/`module`/`exports`, пакет `private`.
  `npm run build` собирает сайт, а не библиотечный entry. Конвертер работает в **synth-entry режиме**:
  бандл синтезируется из `src/`, контракты `.d.ts` слабее обычных — это ожидаемо.
- **Storybook отсутствует** → `shape: "package"`, все превью авторские.
- **Код живёт в git-worktree**: `сайт\.worktrees\react-mvp-redesign`, ветка `feature/react-mvp-redesign`.
  Ветка `main` содержит старый статический MVP и к дизайн-системе отношения не имеет.

## Обязательные шаги перед сборкой

1. **Self-link пакета.** Конвертер ищет `node_modules/suetavpn/package.json` — в собственном репозитории
   его не бывает. Создаётся junction (прав администратора не требует, из корня пакета):

   ```bash
   cmd //c "mklink /J node_modules\\suetavpn ."
   ```

   Без него сборка падает с `ENOENT ... node_modules\suetavpn\package.json`.

2. **Браузер для рендер-проверки.** Сборок `chromium-<build>` в кэше `ms-playwright` нет — там только
   профили Playwright MCP. Поэтому пакет ставится без браузеров
   (`PLAYWRIGHT_SKIP_BROWSER_DOWNLOAD=1 npm i playwright`), а браузер берётся системный:

   ```bash
   DS_CHROMIUM_PATH="C:/Program Files/Google/Chrome/Application/chrome.exe" \
     node .ds-sync/package-validate.mjs ./ds-bundle
   ```

   Запасной вариант — Edge: `C:/Program Files (x86)/Microsoft/Edge/Application/msedge.exe`.
   Скачивать ~200 МБ через `npx playwright install chromium` не нужно.

3. **`cfg.cssEntry` не задавать.** `src/styles/global.css` состоит из `@import`-ов на соседние файлы;
   конвертер дописывает его текстом, и эти импорты повисают — десять ошибок `[CSS_IMPORT_MISSING]`.
   Реальные стили и так попадают в `_ds_bundle.css` через граф esbuild (`main.tsx` → `global.css`).

## Правки в приложении, сделанные ради синхронизации

Все три полезны сами по себе, откатывать их не нужно:

- **Логотип переведён в PNG 256×256** (`src/assets/suetavpn-logo.png`). У конвертера в списке loader-ов
  только `.svg`, `.png`, `.woff`, `.woff2`; `.jpg` роняет сборку, а форк `lib/bundle.mjs` запрещён скиллом.
- **`main.tsx` проверяет наличие `#root`.** Бандл импортирует этот модуль ради стилей, контейнера там нет,
  и `createRoot(null)` обрывал инициализацию всего бандла — из-за этого ни один компонент не
  регистрировался на `window.SuetaVPN`.
- **У `TransactionHistory` появился проп `defaultOpen`.** История была наглухо свёрнута, раскрыть
  программно нечем, и карточка показывала пустой заголовок.
- **Подключён Inter** (`src/styles/fonts.css`, четыре подмножества с кириллицей, ~178 КБ в
  `src/assets/fonts/`). Раньше шрифт был объявлен, но не загружен. Vite выносит woff2 отдельными файлами,
  прод-бандл не тяжелеет; в бандле дизайн-системы они инлайнятся в data-URI, отсюда CSS ~326 КБ.
- **Добавлен `src/design-system/PreviewProvider.tsx`** — обёртка `AppProvider` + `HashRouter` + фон темы.
  Приложением не используется, в прод-сборку не попадает (не входит в граф `main.tsx`).

## Известные особенности превью

- **Порядок CSS в бандле обратный сайту.** В `_ds_bundle.css` первым идёт `landing.css`, затем
  `components.css` и остальное; на сайте `global.css` грузится из `main.tsx`, а `landing.css` позже,
  из `LandingPage.tsx`. На кнопки это не повлияло (проверено), но при расхождениях смотреть сюда первым делом.
- **`BottomNavigation` по умолчанию `display: none`** и включается только медиа-запросом для узких
  экранов — карточка снимается с мобильным вьюпортом `430x520`.
- **Оверлеям нужна высота сцены.** `Drawer` и подобные позиционируются фиксированно относительно ячейки
  (у неё `transform`), а ячейка сжимается по содержимому. В превью задаётся контейнер с явной высотой.
- **`ToastRegion` вылезал за ячейки сетки** — переведён в одиночную карточку через `cfg.overrides`.
- **`LandingPage` раскрывает секции принудительно.** Они появляются по прокрутке, которой в карточке нет;
  превью проставляет им конечное состояние в `useEffect`, сам компонент настоящий.
- **Floor card у `PreviewProvider`** — это норма, техническая обёртка без собственного вида.

## Известные предупреждения рендер-проверки

Их нет: последний прогон дал `30/30 previews render cleanly` и `✓ bundle is complete` без единого warn.

## Грабли платформы (Windows)

- **`EPERM` при удалении `ds-bundle`.** Конвертер сносит каталог сам и падает, если его кто-то держит.
  Лечится циклом в PowerShell до пяти попыток с паузой, потом обычная сборка.
- Файлы, которые поедут на сервер, писать только с `newline="\n"`, иначе bash падает на `\r`.
- Вывод питона с кириллицей требует `PYTHONIOENCODING=utf-8`.

## Грабли выгрузки

- **`write_files` может записать меньше файлов, чем отправлено, и не сообщить об этом.** В одном вызове
  из 75 файлов записалось 73 — молча потерялись `NotificationPopover.d.ts` и `.html`. Ошибки не было.
  **После выгрузки обязательно сверять `list_files` с локальным составом бандла** и досылать недостающее.

## Про сам claude.ai/design

Агент, который строит макеты, может накладывать **собственные** стили поверх компонентов. На первом же
макете его правила для `a` и `a:hover` перекрыли цвет текста у `.button--primary`, и главная кнопка
выглядела выцветшей. В бандле при этом всё было верно (проверено вычисленными стилями). Этот запрет
внесён в `.design-sync/conventions.md`, но если расхождение повторится — сначала проверять бандл
локально (`node .ds-sync/storybook/http-serve.mjs ./ds-bundle`), а не искать ошибку в переносе.

## Re-sync risks

- **Synth-entry режим.** Если в приложении появится настоящая библиотечная сборка, конфиг надо будет
  перевести на `--entry`, и контракты `.d.ts` изменятся.
- **Junction `node_modules/suetavpn` не переживает переустановку зависимостей** — после `npm ci` создавать заново.
- **`DS_CHROMIUM_PATH` жёстко указывает на системный Chrome.** Переставят или удалят — рендер-проверка
  упадёт с `Executable doesn't exist`.
- **Незакоммиченные правки.** На момент синхронизации в worktree висел незакоммиченный визуальный реворк
  от 17-18.08 плюс всё, что описано выше. Дизайн-система собрана именно с этим состоянием.
- **Страницы включены в каталог** (`componentSrcMap` исключает только `App`, `AppRoutes`, `ProtectedRoute`,
  `RouteTransition`, `PublicLayout`). Это осознанное решение: заказчик редактирует существующие экраны
  в Claude Design, а не собирает их заново из деталей.
