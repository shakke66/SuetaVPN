# SuetaVPN — React MVP

Локально работающий frontend личного кабинета SuetaVPN на React, Vite и TypeScript. Он сохраняет состояние в браузере и подготовлен к будущему подключению backend без изменения маршрутов, дизайна и пользовательских сценариев.

## Локальный запуск

Требуется Node.js 24 или новее.

```powershell
npm ci
npm run dev
```

После запуска Vite откройте URL из консоли (по умолчанию `http://127.0.0.1:5173/`).

## Проверки

```powershell
npm run typecheck
npm run test:run
npm run build
```

Production-сборка создаётся в `dist/`. Для локальной проверки собранной версии можно использовать `npm run preview`.

## Маршруты

Публичные маршруты:

- `#/` — лендинг;
- `#/auth` — локальная авторизация.

Защищённые маршруты кабинета:

- `#/dashboard` — главная;
- `#/subscriptions` — текущая подписка;
- `#/purchase` — покупка или продление;
- `#/balance` — баланс, промокод и история операций;
- `#/referral` — реферальная программа;
- `#/support` — обращения и ответы;
- `#/info` — FAQ, соглашение и конфиденциальность;
- `#/profile` — профиль.

## Локальная граница данных

На этом этапе все действия выполняются только через async local adapters. Они имитируют будущую сетевую границу, но не вызывают production API, не списывают деньги, не отправляют email и не выдают VPN-конфигурации.

- Тарифный каталог содержит только БАЗУ и ЭЛИТУ с фиксированными периодными ценами.
- Пополнение, промокод `SUETA10`, покупка, продление, смена тарифа, обращения и уведомления сохраняются локально.
- Состояние хранится под ключом `suetavpn_app_v2`; при первом запуске выполняется безопасная миграция из `suetavpn_mvp_v1`.
- В будущем backend заменит реализации из `src/adapters/local/`, сохранив контракты в `src/adapters/contracts.ts` и UI-слои.

## Интерфейс и доступность

Приложение поддерживает RU/EN, светлую и тёмную темы, статичный фон, адаптивные переходы и устойчивую оболочку кабинета. На мобильных устройствах нижняя навигация остаётся смонтированной между сменами страниц. Формы, диалоги, drawer, popover, onboarding и вкладки поддерживают клавиатуру, focus management и reduced motion.

## Контроль качества

Перед публикацией выполняются typecheck, полный Vitest-набор, production build, проверка whitespace и Browser QA. Последняя локальная регрессия охватывает 128 тестов, полный пользовательский путь и матрицу 360/390/768/1024/1440 px в обеих темах и локалях.

## GitHub Pages

Workflow `.github/workflows/pages.yml` устанавливает зависимости через `npm ci`, запускает typecheck, тесты и Vite build, после чего публикует только `dist/`. Репозиторий должен оставаться приватным; если GitHub Pages недоступен для приватного репозитория на текущем тарифе, не меняйте видимость репозитория без отдельного решения.
